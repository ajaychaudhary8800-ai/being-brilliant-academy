# Student manual

Sign in at `/login` and open `/student` or `/learning-hub`. Keep your password private and sign out on shared devices.

The dashboard provides attendance, homework, timetable, examinations, report cards, fees, certificates, announcements, notifications, and learning progress. Use **Continue Learning** to resume a lesson. Progress is saved periodically. Downloaded study material is available offline on the same device through the installed web app.

Submit assignments before the due date and verify that the correct attachment appears. Start timed tests only when you can finish them; attempts auto-submit at expiry. Use bookmarks, daily challenges, summaries, and flashcards as revision aids. AI-generated content can be incomplete, so verify important answers against faculty notes.

Payment status is authoritative only when shown in the fee ledger with a receipt. Contact the academy if a provider debit does not appear after processing. Certificates can be verified using their QR link.
